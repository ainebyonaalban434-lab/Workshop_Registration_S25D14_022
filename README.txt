**Name:** Ainebyona Alban
**Student number:** S25D14/022

## Description
A responsive workshop registration page built with HTML, CSS and JavaScript.
It has a two-column form, workshop choices created from an array and loop,
HTML and JavaScript validation, and a preview message after a valid
registration. It is a browser-only demonstration: it does not send or save data.

## How to run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Fill in the form with invented details and a practice password.
4. Click "Preview registration".
